# Hao Yan Learn · 皓言学习工作台

A mobile-first, watercolor-styled learning dashboard for Grade 1 (Chinese & English).

## 功能
- 🏠 首页：每日心得 + 程度评分 + 成绩分析图
- 📅 每日任务：5个汉字(拼音笔画)+ 5个词汇 + 5个英文单词(英式发音)
- 🀄 语文：生字 / 词汇 / 成语 / 趣味识字 / 阅读理解 / 中文绘本
- 🔤 英文：ABC 启蒙 / 自然拼读 / 短语 / 语法 / 一年级必学词 / 英文绘本
- ❄️ 雪花飘落
- 🖨️ A4 打印 (确保图片显示)
- 💾 IndexedDB 本地保存 + 一键备份 / 恢复
- 🚫 无后端 / 无广告

## 部署到 GitHub Pages
1. Push to `main` branch.
2. Settings → Pages → Source: `main` / `(root)`.

## 技术栈
- 纯 HTML / CSS / JS (无依赖)
- Web Speech API 语音合成 (英式 en-GB + 中文 zh-CN)
- Web Speech Recognition 跟读练习
- IndexedDB 本地存储
